# Customer Insights Lab

Painel de análise de experiência com dados sintéticos. Compara coortes fictícias e apresenta retenção, satisfação e volume de clientes como hipóteses para investigação, não como métricas de uma empresa real.

## Funcionalidades

- Alternância entre coortes demonstrativas.
- Indicadores recalculados a partir de uma pequena amostra local.
- Gráfico responsivo sem bibliotecas externas.

## Conteúdos relacionados

Estatística, Ciência de Dados, Customer Experience, Customer Success, NPS, CSAT e análise de churn.

## Executar

Abra `index.html` em um navegador.
